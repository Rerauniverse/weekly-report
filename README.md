# weekly-report（工作周报生成器）

把 `daily-report` 生成的日报（或你直接提供的一周工作记录）**跨日聚合、去重、升级为周视角**，产出一份可直接发送的工作周报，并支持推送至邮件 / 飞书 / 钉钉 / 企业微信。

## 与 daily-report 的关系

- **独立可装**：本 skill 自带 `references/weekly-template.md`，不硬依赖 `daily-report` 已安装。
- **口径继承**：归类维度（开发/技术、协作沟通、会议、学习成长、其他）与润色规则原样继承自 daily-report，保证"日报→周报"表述统一。

## 核心能力

1. **自动读取日报归档**：默认扫描 `工作日报_YYYY-MM-DD.md`（可配置 `DAILY_REPORT_DIR` 或指定路径），按自然周（周一~周日）筛选；扫不到则回退让你粘贴一周日报。
2. **周期灵活**：默认本周，也可用 `汇总 10.1–10.14 的周报` 这类表述指定任意起止日期。
3. **跨日聚合去重**：同一事项按标签硬归并或语义软归并，保留时间线；量化指标取最新值+累计；风险按是否跨日再现判定 open / 已解决。
4. **周报独有五板块**：本周概览、关键进展（聚合）、量化成果汇总、风险与阻塞（去重）、下周重点计划。
5. **安全推送**：外发前必须确认渠道与收件人；支持本地归档 `{name}工作周报-{起.M.D}-{止.M.D}.md`（如 `田宇工作周报-10.19-10.25.md`）。

## 触发示例

- "写周报" / "生成周报" / "本周周报"
- "帮我汇总这周" / "把这周日报合成周报"
